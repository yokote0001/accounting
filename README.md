# doc_namer — 請求書 / 支払通知書 PDF の自動リネーム

Fairy effect の雛形で作った PDF を読み取り、
**「7月ご請求 合同会社がっく 御中.pdf」** のような名前に変更します。
Finder で選んで右クリックするだけで、その場でリネームできます。
請求書（INVOICE）と支払通知書（PAYMENT NOTICE）の両方に同じ仕組みで対応します。

| 書類 | 既定のファイル名 |
| --- | --- |
| 請求書 | `7月ご請求 合同会社がっく 御中.pdf` |
| 支払通知書 | `支払通知書 スタジオ コンテナ 御中.pdf` |

## インストール（Mac）

macOS 15 以降、ダウンロードした `.command` ファイルは Finder から起動できません
（「Apple は…マルウェアが含まれていないことを検証できませんでした」と出て、
右クリック →「開く」でも回避できなくなりました）。
そのため、**セットアップだけターミナルから 1 回**実行します。
これが済めば、あとは Finder の右クリックだけで使えます。

1. ZIP を展開して、フォルダを **ホームフォルダ直下** に置きます。

   > ダウンロード・デスクトップ・書類 フォルダは macOS に保護されていて、
   > クイックアクションのプロセスから中のプログラムを起動できません
   > （`Operation not permitted` になります）。置き場所さえ変えれば解決します。
   > 保護された場所で `setup.command` を実行した場合は、移動するか聞かれます。
2. **ターミナル**を開きます（`command + スペース` →「ターミナル」と入力 → Enter）。
3. 次の 1 行を貼り付けて Enter。

```bash
bash "$(ls -dt ~/Downloads/請求書リネーム*/ | head -1)/setup.command"
```

ZIP を Downloads 以外に置いた場合は、`bash ` と入力（bash のあとに半角スペース）してから
`setup.command` をターミナルの窓にドラッグして Enter でも同じです。

Python 環境の準備と、Finder の右クリックメニューへの登録まで自動で行います
（初回は数分かかります）。

Python 3.11 以上が必要です。入っていなければメッセージが出るので、
[python.org](https://www.python.org/downloads/macos/) からインストールしてから
やり直してください。

> **ターミナルを使いたくない場合**
> 「setup.command」をダブルクリック → ブロックのダイアログが出たら「完了」を押し、
> システム設定 →「プライバシーとセキュリティ」→ 下にスクロールして
> 「"setup.command" は…ブロックされました」の横の**「このまま開く」**を押します。
> 同じ手順が `.command` ファイルごとに必要になるので、ターミナルからの実行をおすすめします。

## 使い方

### Finder で選んで右クリック（おすすめ）

**Finder で PDF を選択 → 右クリック →「クイックアクション」→「請求書をリネーム」**

- 選択したファイルが**その場でリネーム**されます。特定のフォルダに入れる必要はありません。
- 複数選択もフォルダの選択もできます。
- 実行前に「この名前に変更します」という確認ダイアログが出ます。
- 請求書・支払通知書として読み取れなかった PDF は、そのまま残ります。

メニューに出てこない場合は、システム設定 →「一般」→「ログイン項目と機能拡張」→
「Finder機能拡張」で「請求書をリネーム」を有効にしてください。

### 右クリックメニューに出てこないとき

**まずこれを試してください。** このフォルダの中の
**「請求書をリネーム.workflow」をダブルクリック** し、出てくる確認で
「インストール」を押します。macOS 自身に登録させる方法なので、
こちらのほうが確実です。

（このバンドルは doc-namer の場所を `~/.config/doc-namer/command` から読むので、
先に「setup.command」を済ませておいてください）

それでも出ない場合:

1. **機能拡張が無効になっている** — システム設定 →「一般」→
   「ログイン項目と機能拡張」→「Finder機能拡張」で
   「請求書をリネーム」にチェックを入れる。
2. **サービス一覧のキャッシュが古い** — 一度ログアウトして入り直す。
3. **調べる** — ターミナルで次を実行し、出力を共有してください。

   ```bash
   bash "$(ls -dt ~/Downloads/請求書リネーム*/ | head -1)/check.command"
   ```

### ダブルクリックで使う

**「rename.command」をダブルクリック** すると、フォルダ／ファイルを聞かれます。
Finder からウィンドウにドラッグして Enter を押すと、変更内容の一覧が出て、
`y` + Enter でその場でリネームします。

こちらも初回は上と同じブロックを受けます。ターミナルから
`bash /path/to/rename.command` として実行するか、
システム設定の「このまま開く」で許可してください。

### ターミナルから使う

セットアップ後は `doc-namer` コマンドが使えます。

```bash
source .venv/bin/activate

doc-namer ~/Desktop/請求書 --move --dry-run  # 結果だけ確認
doc-namer ~/Desktop/請求書 --move            # その場でリネーム
doc-namer ~/Desktop/請求書                   # out/ に別名でコピー（元は残す）
doc-namer a.pdf b.pdf --move
```

### オプション

| オプション | 説明 |
| --- | --- |
| `-o, --out-dir` | 出力先フォルダ（既定: `out`） |
| `--move` | コピーせず元ファイルをその場でリネーム |
| `-n, --dry-run` | 書き込まずに結果だけ表示 |
| `-r, --recursive` | フォルダを再帰的に探す |
| `--overwrite` | 同名ファイルを上書き（既定は ` (2)` を付けて回避） |
| `--json` | 読み取った宛名・日付などを JSON で出力 |
| `--dump-text` | PDF から読み取った本文と判定結果を表示（調査用） |
| `-c, --config` | 設定 TOML のパス（既定: `config.toml`） |

## 何を読み取っているか

1. **書類種別** — 本文に「支払通知書 / PAYMENT NOTICE」があれば支払通知書、
   「請求書 / INVOICE」があれば請求書。支払通知書を先に判定するので、
   本文に「ご請求」の語が混ざっていても取り違えません。
2. **宛名** — 「御中」「様」で終わる行のうち、**いちばん文字が大きい行**。
   明細の `ご紹介手数料(株式会社EDIN様)` のような行末が敬称でないものは拾いません。
3. **月** — 書類種別ごとに決めた日付ラベルを上から順に探します。
   - 請求書: `ご請求日` → `請求日` → `発行日` → `お支払い期限`
   - 支払通知書: `お支払い日` → `お支払日` → `支払日` → `ご請求日`

   請求書は**お支払い期限ではなく「ご請求日」の月**を使います。
   例）ご請求日 2026年7月31日 / お支払い期限 2026年8月31日 → `7月ご請求`

   支払通知書は既定のテンプレートが月を使わないので、日付が読めなくても出力できます。

**必要な情報はテンプレートが決めます。** `template` に `{month}` を書いていなければ
日付は必須になりません。`{month}月お支払い {recipient}` に変えれば、その時点から
日付が必須になります。

次のものは対象から外します（処理はそこで止まりません。理由は標準エラーに出ます）。

- **`._` で始まるファイル** — USB メモリや NAS では、1 ファイルにつき
  `._名前.pdf` という macOS のメタデータ用ファイルが並んで作られます。
  中身は PDF ではないので無視します。
- **宛名が複数見つかった PDF** — 複数社ぶんを 1 つにまとめたファイルです。
  1 社の名前を付けると中身と食い違うので、そのまま残します。
  分割後のファイルを渡してください。
- 請求書・支払通知書として読み取れなかった PDF

## 名前の形を変えたいとき

`config.toml` の `template` を書き換えるだけです。

```toml
[document_types.invoice]
template = "{month}月ご請求 {recipient}"       # 7月ご請求 合同会社がっく 御中
# template = "{ym}_請求書_{recipient_name}"   # 202607_請求書_合同会社がっく
# template = "{year}年{month2}月請求 {recipient}"

[document_types.payment_notice]
template = "{label} {recipient}"               # 支払通知書 スタジオ コンテナ 御中
# template = "{month}月お支払い {recipient}"   # 9月お支払い スタジオ コンテナ 御中
```

使える変数:

| 変数 | 例 |
| --- | --- |
| `{recipient}` | `合同会社がっく 御中` |
| `{recipient_name}` | `合同会社がっく` |
| `{honorific}` | `御中` |
| `{month}` / `{month2}` | `7` / `07` |
| `{year}` / `{yy}` | `2026` / `26` |
| `{day}` / `{day2}` | `31` / `31` |
| `{ym}` | `202607` |
| `{label}` / `{type}` | `請求書` / `invoice` |

設定ファイルは次の順で探します。先に見つかったほうが使われます。

1. `~/.config/doc-namer/config.toml`（どこにインストールしても効く個人設定）
2. このリポジトリ直下の `config.toml`

見積書など新しい書類を増やすときは `[document_types.〇〇]` を足して、
`detect` / `date_labels` / `template` / `priority` を書きます。

## 補足: ファイル名について

`.command` ファイルを ASCII 名にしているのは意図的です。
macOS はファイル名を NFD（分解済み）で保持するため、
`セットアップ.command` のように濁点・半濁点を含む名前は
`find -name "セットアップ.command"` のような NFC の文字列と一致せず、
「見つからない」と誤解される事故が起きます。
（`請求書をリネーム.workflow` は濁点を含まないので影響を受けません）

## テスト

```bash
.venv/bin/pip install -e ".[dev]"
.venv/bin/python -m pytest tests -q
```

PDF を使う end-to-end テストも含め、テスト用の PDF はその場で生成するので、
実際の請求書をリポジトリに置く必要はありません。
